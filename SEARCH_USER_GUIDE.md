## 💡 Search Tips

### Be General
- ✅ `"memory"` finds all memory games
- ❌ `"memory sequence 2"` might miss results

### Use Keywords
- ✅ `"anxiety"` finds all anxiety-related games
- ✅ `"breathing"` finds breathing exercises
- ✅ `"impulse"` finds impulse control games

### Don't Worry About:
- ✅ **Case** - `"Memory"` = `"memory"` = `"MEMORY"`
- ✅ **Spaces** - Extra spaces are ignored
- ✅ **Spelling** - Partial matches work (e.g., `"breath"` finds `"breathing"`)

## ❓ Troubleshooting

### "No results found"
**Try:**
- ✅ Use fewer characters
- ✅ Try a synonym (e.g., "talk" instead of "chat")
- ✅ Search by category instead of specific name
- ✅ Check spelling

### Results Don't Match
**Remember:**
- The search looks in titles, descriptions, AND keywords
- Sometimes a game appears because it matches a keyword you didn't expect
- Read the description to understand why it matched

### Search Not Working
**Check:**
- Are you logged in?
- Is your internet connected?
- Try refreshing the page
- Clear search and try again
